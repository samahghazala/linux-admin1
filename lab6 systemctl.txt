##Part 1: Package Discovery & Initial Service Setup ##
  
  Exercise 1.1: Package Manager Documentation Open the manual page for the primary package manager command on RHEL (dnf) to learn how to search for and install packages:
  ==>man dnf 
  
  Exercise 1.2: Install and Deploy nginx
   1. Install the nginx web server package using dnf. 
   ==> sudo dnf install nginx -y
   
   2. Start the nginx service. 
   ==> systemctl start nginx
   
   3. Enable nginx so that it starts automatically upon system boot. 
   ==>systemctl enable nginx
   
   4. Verify and confirm that nginx is currently active (running) and enabled. 
   ==>systemctl status nginx
    ● nginx.service - The nginx HTTP and reverse proxy server
     Loaded: loaded (/usr/lib/systemd/system/nginx.service; enabled; preset: disabled)
     Active: active (running) since Thu 2026-10-08 00:18:23 EEST; 1min 53s ago

##Part 2: Port Conflict Analysis & Service Masking ##
   
  Exercise 2.1: Install and Launch httpd 
   1. Install the Apache HTTP Server package (httpd) using dnf. 
   ==>sudo dnf install httpd -y
   
   2. Attempt to start the httpd service while nginx is actively running.
   ==> sudo systemctl start httpd
	    Job for httpd.service failed because the control process exited with error code.
		See "systemctl status httpd.service" and "journalctl -xeu httpd.service" for details.
		
   3. Observe the output returned by the system. Did httpd start successfully or fail? 
   ==> journalctl -xeu httpd.service
		The unit httpd.service has entered the 'failed' state with result 'exit-code'.
        Oct 08 00:25:24 localhost.localdomain systemd[1]: Failed to start httpd.service - The Apach>
        Subject: A start job for unit httpd.service has failed
        Defined-By: systemd
   
  Exercise 2.2: Log Inspection & Root Cause Analysis
  1. Use journalctl to inspect the recent logs generated specifically by the httpd unit. 
  ==> journalctl -xeu httpd.service
  
  2. Review the log output to locate the error message.
  ==>Oct 08 00:25:24 localhost.localdomain systemd[1]: Failed to start httpd.service - The Apach>
	 Subject: A start job for unit httpd.service has failed
	 
  3. Question: What is the specific error message and port number causing httpd to fail? 
  ==>The job identifier is 21112 and the job result is failed.
  
  
  Exercise 2.3: Service Masking & Failover 
  1. Stop the running nginx service.
  ==> sudo systemctl stop nginx
  
  2. Mask the nginx service unit to prevent any user or automated script from starting it.
  ==> sudo systemctl mask nginx
	  Created symlink '/etc/systemd/system/nginx.service' → '/dev/null'.
      
	  
  3. Test your mask configuration by explicitly attempting to start nginx.
  ==> sudo systemctl start nginx
	  Failed to start nginx.service: Unit nginx.service is masked.
	  
  4. Question: What error or message does systemctl return when you attempt to start a masked service? 
  ==> Failed to start nginx.service: Unit nginx.service is masked.
  
  5. Start and enable the httpd service now that nginx is masked and stopped. 
  ==>  sudo systemctl start httpd
	   

  6. Verify that httpd is currently active (running).
  ==> sudo systemctl status httpd
		● httpd.service - The Apache HTTP Server
		Loaded: loaded (/usr/lib/systemd/system/httpd.service; disabled; preset: disabled)
		Active: active (running) since Thu 2026-10-08 00:47:09 EEST; 16s ago

  Part 4: Environment Cleanup
  Exercise 4.1: System Restoration 
  1. Unmask the nginx service. 
  ==> sudo systemctl unmask nginx
      Removed '/etc/systemd/system/nginx.service'.


  2. Stop both httpd and nginx services. 
  ==>  sudo systemctl stop nginx
       sudo systemctl stop httpd
  
  3. Disable both httpd and nginx from starting at system boot. 
  ==>   sudo systemctl disable httpd
        sudo systemctl disable nginx
        Removed '/etc/systemd/system/multi-user.target.wants/nginx.service'.

  4. Remove both httpd and nginx packages from the system using dnf. 
  ==>  sudo dnf remove httpd nginx
